# 平日禁酒トラッカー

平日だけ禁酒するためのカレンダーアプリ。連続記録・旦那さんとの精算・体重を1画面で管理します。
`index.html` 1ファイルだけの静的アプリなので、ブラウザで開けばそのまま動きます（サーバー不要）。

## つかい方

1. `index.html` をブラウザで開く（スマホなら「ホーム画面に追加」しておくとアプリっぽく使えます）
2. カレンダーの日付をタップ → **禁酒した / 飲んだ / 未記録** を選ぶ
3. 同じ画面で体重も入力（任意）

## 画面

| 場所 | 内容 |
| --- | --- |
| 一番上 | **平日禁酒の連続記録**（土日祝はスキップするので、休みの日に飲んでも途切れません）と最長記録 |
| その下 | **今月の精算額**（旦那さんからもらう／払う）、月末精算日までの残り日数、禁酒日数・飲んだ日数・残り平日・満額いくらか |
| カレンダー | 日ごとの記録。🍵＝禁酒、🍺＝飲んだ、数字＝その日の体重。「祝」バッジ付きの日は祝日 |
| 体重の記録 | 現在／開始から／今月／目標までの増減と、直近90日の推移グラフ |
| 月別の精算 | 月ごとの精算額の履歴（タップでその月のカレンダーへ）と、旦那さんとの累計の貸し借り |

## ルール（設定で変えられます）

- **対象日は平日のみ。** 対象日に禁酒すると **+500円**、飲むと **−500円**。金額は設定で変更可
- **土日は対象外。** 記録はできますが、精算にも連続記録にも影響しません
- **祝日も既定では対象外**（設定でオフにすると、祝日も平日として精算対象になります）。祝日は日本の祝日法にもとづき自動計算（振替休日・国民の休日も対応）
- 今日がまだ未記録でも連続記録は途切れません（過去の未記録日はそこで止まります）
- 月末精算：その月の `禁酒日数 × 500 − 飲んだ日数 × 500` が精算額。プラスならもらう、マイナスなら払う

## データについて

記録はブラウザの localStorage（この端末のなか）にだけ保存されます。サーバーには何も送信しません。
機種変更やブラウザのデータ削除で消えるので、設定の **「データを書き出す」** でときどきバックアップを取ってください（JSONファイル。「読み込む」で復元できます）。
