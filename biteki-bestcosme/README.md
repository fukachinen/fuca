## スクリプトについて

元ファイルにはセル内画像（richData）・Excelテーブル定義・図形が含まれており、openpyxl で
保存し直すとこれらが失われる。そのため XML を直接編集している。

行を追加する際は、シートの行番号・セル参照だけでなく、テーブルの `ref`、`dimension`、
図形（drawing）のアンカー行もあわせてずらす必要がある。

セル内画像は以下の参照チェーンで保持されている。追記時はすべて末尾に足し、
既存の記入例（vm=1, 2）に影響を与えないようにしている。

```
cell の vm 属性
  -> xl/metadata.xml  valueMetadata
  -> xl/metadata.xml  futureMetadata (xlrd:rvb)
  -> xl/richData/rdrichvalue.xml     rv
  -> xl/richData/richValueRel.xml    rel
  -> xl/richData/_rels/richValueRel.xml.rels
  -> xl/media/*
```

```
python3 make.py
```
