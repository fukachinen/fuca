# Google Chat「やっときます」文案メーカー

Google Chatで自分が「やっときます」「送っときます」などと送ると、5分以内にその用事の文案がメールで届きます。

- 「送っときます」の場合：相手に送る本文
- 「やっときます」「確認します」の場合：終わったときにチャットに返す完了報告

数字・URL・日付など自分にしか分からない部分は【　】の空欄になります。

## 動く仕組み

1. Apps Scriptが5分おきに、自分が参加しているスペースとDMの新しい投稿を確認
2. 自分の投稿のうち「やっとき」「送っとき」「確認します」などを含むものだけを選ぶ
3. 直前の会話（最大15件）と一緒にClaudeに渡して、本当に約束かどうかを判定し、文案を作る
4. 約束だったら、自分宛てに「【文案】◯◯」というメールを送る

## 始める前に確認すること

- **会社のルール：** チャットの内容が外部のAI（Anthropic の Claude API）に送られます。社内で許可されているか確認してください。
- **Claude APIキー：** https://console.anthropic.com で発行します（利用料がかかります）。

## セットアップ（初回だけ・15分くらい）

### 1. Google Cloudプロジェクトを用意する

Google Chat APIは、Apps Scriptの初期設定のままでは使えないため、この準備が必要です。

1. https://console.cloud.google.com で新しいプロジェクトを作る
2. 「APIとサービス」→「ライブラリ」で **Google Chat API** と **People API** を有効にする
3. 「APIとサービス」→「OAuth同意画面」で、ユーザーの種類を **内部** にして作成する（アプリ名とメールアドレスだけ入力すればOK）
4. Google Chat APIの「構成」タブで、アプリ名・アバターURL・説明を入れて保存する（アバターURLは何かの画像URLでOK。チャットには表示されません）
5. ダッシュボードに出ている **プロジェクト番号**（数字）を控えておく

### 2. Apps Scriptを作る

1. https://script.google.com で「新しいプロジェクト」を作る
2. 左の歯車（プロジェクトの設定）を開き、次の2つを設定する
   - 「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック
   - 「Google Cloud Platform（GCP）プロジェクト」で「プロジェクトを変更」を押し、控えたプロジェクト番号を入れる
3. 同じ画面の一番下「スクリプト プロパティ」に次を追加する
   - プロパティ：`ANTHROPIC_API_KEY`
   - 値：ClaudeのAPIキー
4. エディタに戻り、`appsscript.json` と `コード.gs` の中身を、このフォルダの `appsscript.json` と `Code.gs` の内容で丸ごと置き換えて保存する

### 3. 動作確認と開始

1. 上のメニューで関数 `testDraft` を選んで「実行」→ 権限の確認が出たら許可する
   → 「【文案】…」というテストメールが届けばOK
2. 関数 `setup` を選んで「実行」
   → これで5分おきの自動チェックが始まります

## 止めたいとき

関数 `stop` を実行してください。

## 調整できるところ（`Code.gs` の先頭の `CONFIG`）

| 項目 | 内容 |
|---|---|
| `KEYWORDS` | どの言葉を含む投稿を候補にするか。拾ってほしい言い回しがあればここに足す |
| `INTERVAL_MINUTES` | チェックする間隔（1, 5, 10, 15, 30） |
| `CONTEXT_MESSAGES` | 文案づくりに渡す直前の会話の件数 |

## 注意

- Chat APIでは相手の名前を取得できないことが多いため、会話は「自分」「相手A」「相手B」として渡しています。宛先の名前は、会話の中の「◯◯さん」などから推測します。
- スレッドがあるスペースでは、別のスレッドの投稿も文脈として混ざることがあります。
- 文案を作れなかったときは「【文案】作成に失敗しました」というメールが届きます。
